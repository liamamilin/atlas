## 1. 本轮实现

M4 已从底层探测模块进入项目工作台。用户可以：

1. 用已确认的本版需求和不可变文档版本建立活动迭代。
2. 在迭代内创建 `analysis`、`document` 或 `code` 任务，固定允许写入路径和验证命令。
3. 从项目页启动 OpenCode、查看运行状态、处理权限请求或问题，并停止执行。
4. 查看 Atlas 自己比较得到的新增、修改、删除与越界文件，不依赖 OpenCode `diff` 是否完整。
5. 查看结构化命令证据：命令、是否属于预先固定的验证、退出码、输出和截断状态。
6. 将 agent 执行完成与产品验收分开处理；只有记录 `passed` 或明确 `waived` 后，迭代才能完成。

## 2. Atlas 拥有的执行输入

`ProjectStore` schema 升级为 v4。任务新增：

- 任务类型。
- 工作区内的相对写入路径。
- 预先固定的验证命令。

执行记录新增：

- 绝对工作目录。
- 项目、迭代、任务、文档版本、确认需求和项目基线的不可变输入摘要。
- 引擎实际能力表。`follow_up` 暂时明确为 `false`，不把尚未接入的继续会话伪装成已支持。

启动前必须满足：任务属于活动迭代，所有绑定需求仍是用户确认的本版范围，存在已接受项目基线，当前工作区内容指纹与该基线一致。检查不通过时不创建引擎会话。

SQLite 局部唯一索引阻止同一绝对工作目录同时出现两个活动执行。即使多个 API 请求并发进入，数据库也是最后一道互斥边界。

## 3. OpenCode 适配与运行时

`opencode_client.py` 新增了待回答问题的查询、回复和拒绝接口；`reconcile()` 现在同时读取会话、状态、消息、引擎差异、权限与问题快照。

`opencode_runtime.py` 优先连接 `ATLAS_OPENCODE_URL` 指定的本机服务；没有配置时，由 Atlas API 进程启动一个绑定 `127.0.0.1` 随机端口的 `opencode serve --pure`。运行时禁用外部目录、Web 和子任务；代码任务启用 Bash，分析任务禁用写入与 Bash。

SSE 能力仍保留在适配层，当前项目页轮询官方快照端点。这是可恢复性选择：页面断开后不需要重放事件才能恢复状态。

## 4. 成果与验证证据

Atlas 从 OpenCode 消息的 tool parts 中提取命令及退出码，并把执行结束时的文件快照与执行前快照比较。因此页面的“验证通过”依据是结构化命令记录，文件变化依据是 Atlas 指纹，不是只显示 agent 的自述。

项目导出 manifest 升级为 schema 3，新增：

- `iterations.md`：迭代、任务、写入范围、验收和执行摘要。
- `execution-records.json`：完整的机器可读执行记录。
- `handoffs/<task-id>.md` 和 `.json`：不依赖旧 OpenCode 会话的任务交接材料。
- manifest 中的迭代、任务、执行计数，活动迭代和待验收任务。

2. 创建代码任务 `tsk_fb3334ece3b246dc936b0674e910c241`，写入范围仅为 `src`，验证命令为 `python3 -m unittest discover -s tests`。
3. 启动执行 `exe_78d8e35b97f74898b4d3b26b5520e956`，OpenCode 会话为 `ses_f6654fe97ffep2ijg3f4oUjZEZ`。
4. OpenCode 读取目标文件、只修改 `src/counter.py`，然后执行固定命令；命令退出码为 0，输出为 1 项测试通过。
5. Atlas 的执行前后快照独立报告一个修改文件 `src/counter.py`，没有越界变化。
6. 页面在执行完成后仍显示验收 `pending`；人工记录证据并设为 `passed` 后，迭代才成功完成。
7. 停止 Atlas API 及其拥有的 OpenCode 子进程，然后重启 API。新进程启动的 OpenCode 服务仍能按旧 session ID 读取消息；Atlas 补齐了命令、退出码和输出，没有重复执行任务。

9. 从页面导出的 schema 3 ZIP 包含基线、迭代、任务、完整执行证据和 Markdown/JSON 交接包。

本次 Bash 没有产生新的权限请求，表明本机 OpenCode 已有匹配的持久授权。权限等待与回复的真实引擎行为已在 M0 验证；本轮新增项目 API、状态投影数据和页面操作。OpenCode 提问接口已有适配器与页面，但本次任务不需要提问，不将它记为真实提问样例。
