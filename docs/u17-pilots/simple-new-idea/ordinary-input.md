# 普通生成固定输入

## 项目目标

为同时推进多个个人项目的个人开发者设计一款本地优先的个人日计划器。

首轮只验证以下能力：

1. 用户可以创建多个项目及其任务。
2. 用户可以从不同项目选择任务，形成指定日期的“当天承诺”清单。
3. 移除当天承诺不会删除原项目任务。
4. 数据持久保存在本地；进程停止并重新启动后，项目、任务和当天选择关系保持一致。

首轮范围不包含手动时间块、冲突提示、外部日历、自动排程、账号、云同步或团队协作。

## 给模型的请求

仅依据随本请求附带的三份 Application Atlas 类型文档，生成一份可以交给开发者实施的中文 Markdown 方案。不要搜索网络、读取其他项目文件、执行代码或修改文件。不要追问；缺少的信息列为待决定项。

方案应覆盖：

- 目标用户与需要解决的问题。
- 本轮范围、明确不做的内容和主要用户流程。
- 核心数据模型及对象关系。
- 页面或交互结构。
- 适合本地运行的技术方案。
- 按依赖排序的开发任务。
- 可独立执行的验收办法。
- 关键风险、假设和待决定项。

请明确区分三类内容：来源文档直接支持的事实、针对本项目作出的方案假设、仍需决定的信息。不要使用 Atlas 项目工作流、稳定需求 ID、文档依赖图或结构化校验格式。
