# 中断与会话不可用后的继续开发：范围与时间记录

状态：规划模板，尚未开始实际试点。

## 目标

验证执行被停止、浏览器关闭或旧会话不可用后，Atlas 能否仅凭项目状态、工作区证据和交接包，让新会话安全理解并继续下一项工作。

## 固定流程

1. 固定任务输入版本、工作区基线、允许写入路径、验证命令和副作用确认点。
2. 模拟中断，保存已完成命令、输出、文件差异、应用状态和未完成动作。
3. 生成交接包，分开记录 agent 报告、命令证据、应用状态和产品验收状态。
4. 使用新会话读取交接包和当前工作区，核对基线、外部变化和待确认动作。
5. 只从下一项安全动作继续；需要副作用的步骤必须再次确认，不能整段重放。
6. 重新记录继续执行、差异、应用和独立验收，并保留中断前的原始记录。

## 范围边界

首轮选择一个允许写入路径较小、验证命令固定的任务，只模拟一次中断和一次恢复。暂不覆盖多 agent 并行、云端迁移或跨项目合并。
