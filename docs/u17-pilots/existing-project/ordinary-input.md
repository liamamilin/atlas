# 普通生成固定输入

## 当前项目

这是一个本地 Python 清单命令行工具，代码和测试只有两个文件：`todo.py` 与 `test_todo.py`。它把任务保存到本地 `tasks.json`，支持 `add`、`list` 和 `done`，现有回归命令是：

```bash
python3 -m unittest -v
```

当前基线测试 6 项全部通过。

## 改进目标

改进本地清单 CLI 的持久化可靠性：写入采用安全的原子替换，读取损坏的 `tasks.json` 时给出明确且可恢复的错误，同时保持现有 `add`、`list`、`done` 行为兼容。

## 范围

需要覆盖：

1. 正常 `add` 和 `done` 写入后数据完整可读取。
2. 模拟写入失败时，旧的 `tasks.json` 保持不变。
3. `tasks.json` 损坏或不是有效 JSON 时，命令返回非零退出码和可理解错误，不静默重置数据。
4. 现有成功输出、任务字段、跨进程读取和回归测试保持兼容。

不做新增任务命令、图形界面、多人协作、云同步、数据库迁移或字段语义变更。只允许修改 `todo.py` 和 `test_todo.py`。
