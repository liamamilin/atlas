# 高风险数据恢复与版本迁移：范围与时间记录

状态：规划模板，尚未开始实际试点。

## 目标

验证 Atlas 能否把一次可能造成不可逆影响的数据恢复或版本迁移，组织成可预览、可确认、可回滚、可独立验收的产品流程。

## 固定流程

1. 建立只读基线，记录数据格式、数量、校验结果、版本和未检查范围。
2. 固定本次目标、允许处理的文件、禁止触碰的目录和备份保留期限。
3. 在隔离副本生成迁移预览，明确新增、删除、转换、冲突和无法解析的记录。
4. 生成安全快照或备份，记录位置和校验和；用户确认预览后才允许写回。
5. 执行迁移并验证旧格式读取、新格式读取、完整性和回滚路径。
6. 应用前再次检查外部变化，冲突或过期基线必须停止覆盖并重新确认。
7. 独立验收用户可观察行为，导出前后版本、差异、备份和恢复说明。

## 范围边界

首轮只选择一个可独立复验的小型数据集和一种格式变化。不得把云端同步、批量跨项目迁移或自动修复不可解析记录同时纳入首轮。
