# 范围与时间线

目标：验证操作者能否只通过应用助手（右下角「助手」/ ⌘K）完成一个项目的全流程。流程为：建项目 → 资料分析 → 采用需求 → 处理待决问题 → 确认范围 → 生成文档 → 审阅 → 基线 → 迭代 → 任务 → 执行 → 应用 → 验收 → 完成迭代。

操作者只发自然语言消息，并在确认卡片上点「执行」或「取消」，不直接调用写接口。发现 Atlas 缺陷时就地修复，修复后继续，所以时间线里含修复耗时。

例外，以下操作没有经过助手：

- 执行进度同步：脚本反复调用 `POST …/executions/{id}/reconcile`，等同于网页每 1.5 秒的轮询。包括 API 重启后把 `exe_580cd679…` 从 `unknown` 同步为 `completed` 的那一次。
- 排查 409 时，直接调用过一次 `POST …/tasks/{id}/executions`（deepseek），返回 409，没有产生执行。

本案例没有按 `U17_M5_PILOT_PLAN.md` §2 做普通生成对照；操作者由开发者模拟，真实用户观察项记为「未观察」。
