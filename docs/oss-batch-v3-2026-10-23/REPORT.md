# 三叶子分批采集与增量复验

验收日期：2026-10-23。范围：现有阅读器、图表应用、密码管理器三个叶子；个人知识管理与历史工厂数据保留。此次验证的是场景生成、真实搜索、官方资料提取、条件适用和增量存储，未扩大到其他叶子。

## 已交付的行为

- 新场景和原场景并存，不因名称或用途相近而阻止采集。
- 每轮实际请求 GitHub 搜索；模型不能添加搜索结果之外的仓库。已发现候选全部入库，元数据只决定读取顺序，不再通过模型初筛或截断候选名单。
- 默认每叶子每批读取 8 个候选。读取 README、许可证和至多 2 份仓库内官方文字文档；开发计划、测试、Agent 指令和样例插件不能证明产品功能。正式发布说明可以作为已发布功能的依据。
- 每条介绍、功能和关联绑定具体原文、内容摘要及不可变 Git blob。合理推断使用 `conditional`，显示输入源、格式或配置等实际前提；不能用“如果产品支持某个未证实功能”来补证据。
- 候选队列展示待处理、已采纳、待补依据、已排除和失败项。普通更新推进后续候选，已知来源变化的项目优先复核；`--recheck` 用于重复验证上一批。
- 设置页增加 GitHub Token 保存、测试连接和清除入口。保存后立即生效；输入留空保留已有凭据。凭据文件权限为 0600，接口只返回是否配置及配置来源，不回传密钥，不进入模型输入或快照。

## 相关性和真实性复核

对最终 21 个项目的 204 处引文检查了原文存在性、引用文档、内容摘要和不可变链接；另外逐项核对陈述与场景是否真正被资料支持。引文存在本身不等于关联成立。

- **补足真实发现**：next-ai-draw-io 来自实际搜索候选，经读取官方资料后建卡，未依赖预先整理的项目名单。候选超过单批容量时保留队列，后续继续读取。
- **条件适用**：阅读器用于论文或特定主题追踪，需要相应来源提供可订阅内容；卡片列出前提，不把所有内容平台都说成已支持。
- **收窄图表关联**：Mermaid 的文本图表能力不能证明原生拖拽图形、设备库和连线操作。移除两条不成立的关联，通用流程图用于审批梳理时标明条件，保留三条有依据的关联。
- **扩展官方资料**：KeeWeb 密码生成功能依据正式发布说明；开发计划、Agent 检查表和样例插件不作为功能证明。Bitwarden Android 的本批可读资料主要是构建及依赖说明，保留为待补依据，不据依赖库用途生成产品功能。
- **许可证纠正**：Folo 主体 AGPL 文本另含素材不可再分发条件；drawio 代码许可与图标等素材限制分开展示；Keyguard 的许可证仅声明保留全部权利。这三个仓库均不进入“已核验开源许可证”筛选，卡片介绍也不笼统称为开源。
- **保留真实失败**：`Sfedfcv/redesigned-pancake` 仓库元数据可读但 README 不可读，保留失败及原因，没有生成卡片。
- **读取后排除**：数据库图工具、绘图库、无密码库的无状态密码生成器、密码规则数据集等邻近项目，有实际读取和排除原因；不是依据标题提前删除。

尚有真实缺口：图表的三个场景各只有 2 个项目；密码生成场景只有 1 个，家庭共享与团队新成员凭据配置仍为 0。页面如实展示。后续应继续消费现有候选队列，再判断覆盖是否足够。

## 增量更新实测

最终同批复跑仍进行了 15 次真实 GitHub 搜索，并重新检查仓库身份和公开状态；资料未变时复用已核验来源和模型结果。

| 叶子 | 新建 | 更新 | 未变 | 新模型调用 | 读取失败 |
|---|---:|---:|---:|---:|---:|
| 阅读器 | 0 | 0 | 8 | 0 | 0 |
| 图表应用 | 0 | 0 | 3 | 0 | 1 |
| 密码管理器 | 0 | 0 | 5 | 0 | 0 |

图表的其余 4 条为已有排除决定；密码管理器的其余 3 条为已有排除或待补依据。它们不计为成功卡片。重复运行没有重复建项，候选状态保留。

原始首次运行及资料策略修正过程保留在 `first-pass/`、`source-policy-recheck*/`、`recheck*/`；最终复跑以 [incremental-final/](incremental-final/) 为准。各目录的 `audit/` 保存对应实际搜索、候选选择、资料读取与模型调用凭据，不能把早期中间结果当作最终发布结果。早期出现过瞬时网络错误、模型 JSON 截断以及修复响应结构差异，经过有界重试和解析修正；未伪装成从未发生。

模型使用现有 Open Design 配置，请求模型为 `deepseek-v4.1-flash`，实际响应记录为 `deepseek-flash`。只发送公开分类和已读取的公开仓库资料；GitHub Token 仅用于 GitHub 请求授权。

## 覆盖限制与下一步

本轮搜索每个查询只取前 30 个结果，要求至少 100 Stars、非 fork、非归档；完整候选数和搜索截断信息保存在审计中。这会漏掉长尾项目，不能据此宣称找全。资料提取目前只读取仓库内官方文字文档，不自动爬取站外帮助中心；核验也不表示实际部署过第三方应用。

当前适合继续分批读取这三个叶子的 131 条待处理候选，并复查新增卡片质量。暂未向更多叶子自动扩量；场景重复保留，不作为阻塞条件。
