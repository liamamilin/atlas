# U17 M0–M4 验证档案

这些文档记录 U17 已完成里程碑的实现与验证过程。它们保留原始证据和当时的阶段描述，不再承担当前开发计划；当前状态与下一步以 [U17 开发规划](../../U17_DEVELOPMENT_PLAN.md)和 [M5 试点计划](../../U17_M5_PILOT_PLAN.md)为准。

## 档案目录

- [M0 验证](U17_M0_VALIDATION.md)：资料读取、执行引擎、状态存储和独立交接。
- [M1 验证](U17_M1_VALIDATION.md)：项目、搜索、资料阅读与固定来源版本。
- [M2 基础闭环](U17_M2_FOUNDATION_VALIDATION.md)：需求、决定、关联文档、版本传播与导出。
- [M2 生成](U17_M2_GENERATION_VALIDATION.md)：固定输入分析和依赖化文档集合。
- [M2 章节修改](U17_M2_REVISION_VALIDATION.md)：章节级修改、差异审阅和并发保护。
- [M2 价值分析](U17_M2_VALUE_VALIDATION.md)：只提供建议的价值报告边界。
- [M3 基线](U17_M3_BASELINE_VALIDATION.md)：工作区快照、证据分层和外部变化检查。
- [M3 改进方案](U17_M3_IMPROVEMENT_VALIDATION.md)：已有项目目标驱动改进闭环。
- [M4 执行](U17_M4_EXECUTION_VALIDATION.md)：OpenCode 隔离执行、应用、验收、恢复和交接。

M0–M4 的最终完成状态已经汇总到开发规划；核心连续流程的最新复验见 [U17 核心主线验证](../../U17_CORE_PATH_VALIDATION.md)。
