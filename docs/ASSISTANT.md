# 应用助手

每个页面右下角都有「助手」按钮（快捷键 ⌘K / Ctrl+K）。用一句话描述要做的事，助手会查询资料、调用应用接口，或打开对应页面。

## 能做什么

- 查找软件类型和开源项目，打开类型页、项目详情页或任意页面。
- 收藏项目，为某个类型重新收集开源项目。
- 项目工作台：创建项目、固定资料、添加和确认需求、记录决定、启动生成并采用结果、管理文档、迭代、任务和执行，以及导出和备份。
- 分类草稿和模板工厂：查看状态，新建草稿，暂停、继续或重试批次。

助手知道你当前所在的页面，所以可以说「收藏当前这个项目」。

## 安全规则

- **每次修改都要你确认。** 读取会立即执行；写操作会显示确认卡片，列出请求方法、路径和内容，你点「执行」后才会运行。执行的就是卡片上的内容，模型之后无法再改。如果你直接发送新消息，待确认的操作会被取消。
- **危险操作需要你输入确认文字。** 例如删除项目时，要输入项目 ID。模型自己填写的确认值会被丢弃。
- **只能调用登记过的写接口。** 写操作必须匹配 `atlas_assistant.ROUTES` 中的条目，否则会被拒绝。模型和 GitHub 凭据只能在设置页修改，对话接口本身也不能由助手调用。
- **统一走应用接口。** 助手通过本机 HTTP 调用和网页相同的接口，校验、锁和边界检查都完全一样。
- **调用有上限。** 每轮最多 10 次模型调用、240 秒和 80k tokens。接口和语料返回的内容只作为数据，不会被当作指令执行。

## 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET / POST | `/api/assistant/threads` | 对话列表 / 新建对话 |
| GET / DELETE | `/api/assistant/threads/{id}` | 读取对话 / 删除对话（`confirm: "delete_assistant_thread"`） |
| POST | `/api/assistant/threads/{id}/messages` | 发送消息 `{content, page?}`，在后台运行 |
| POST | `/api/assistant/threads/{id}/actions/{action_id}` | 处理待确认操作 `{decision: "approve"\|"reject", typed?}` |

对话保存在 `application-atlas-production-pack/atlas/assistant/`，只保存在本机，不进入 git。

## 扩展

新增写接口时，在 `ROUTES` 中登记方法、路径正则、说明、请求体提示和风险级别（`write` / `destructive`）。危险操作还要填写 `typed`（需要输入的确认文字）和 `field`（确认值写入的请求体字段）。
