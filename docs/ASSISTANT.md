# 应用助手

每个页面右下角都有「助手」按钮（快捷键 ⌘K / Ctrl+K）。用一句话描述要做的事，助手会查询资料、调用应用接口，或打开对应页面。

## 能做什么

- 查找软件类型和开源项目，打开类型页、项目详情页或任意页面。
- 收藏项目，为某个类型重新收集开源项目。
- 项目工作台：创建项目、固定资料、添加和确认需求、记录决定、处理待决问题、启动生成并采用结果、管理文档、迭代、任务和执行（含回答执行中的提问和权限请求），以及导出、备份、从备份恢复和删除备份。
- 分类草稿：新建、编辑正文、重新生成、翻译、查重、入库和删除。
- 模板工厂：新建或修改场景，创建、暂停、继续、取消批次，重试任务。
- 设置：切换默认模型和备用模型，测试模型服务连接。

助手知道你当前所在的页面，所以可以说「收藏当前这个项目」。

## 安全规则

- **每次修改都要你确认。** 读取会立即执行；写操作会显示确认卡片，列出请求方法、路径和内容，你点「执行」后才会运行。执行的就是卡片上的内容，模型之后无法再改。如果你直接发送新消息，待确认的操作会被取消。唯一的例外是「同步执行状态」（`POST …/executions/{id}/reconcile`）：它只从执行引擎拉取最新状态，不改动你的数据，所以助手查进度时会直接调用。
- **危险操作需要你输入确认文字。** 例如删除项目时要输入项目 ID，删除备份要输入 `delete_backup`，从备份恢复要输入 `restore_to_new_store`。模型自己填写的确认值会被丢弃。
- **只能调用登记过的写接口。** 写操作必须匹配 `atlas_assistant.ROUTES` 中的条目，否则会被拒绝。添加或删除模型服务、导入凭据、修改 embedding 地址和 GitHub 设置只能在设置页完成，因为它们涉及密钥或接收密钥的地址；对话接口本身也不能由助手调用。
- **统一走应用接口。** 助手通过本机 HTTP 调用和网页相同的接口，校验、锁和边界检查都完全一样。
- **调用有上限。** 每轮最多 10 次模型调用、240 秒和 80k tokens。接口和语料返回的内容只作为数据，不会被当作指令执行。

## 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET / POST | `/api/assistant/threads` | 对话列表 / 新建对话 |
| GET / DELETE | `/api/assistant/threads/{id}` | 读取对话 / 删除对话（`confirm: "delete_assistant_thread"`） |
| POST | `/api/assistant/threads/{id}/messages` | 发送消息 `{content, page?}`，在后台运行 |
| POST | `/api/assistant/threads/{id}/actions/{action_id}` | 处理待确认操作 `{decision: "approve"\|"reject", typed?}` |

对话保存在 `application-atlas-production-pack/atlas/assistant/`，只保存在本机，不进入 git。

## 扩展

新增写接口时，在 `ROUTES` 中登记方法、路径正则、说明、请求体提示和风险级别（`write` / `destructive`；只同步外部状态、不改动用户数据的接口可以用 `sync`，免确认直接执行）。危险操作还要填写 `typed`（需要输入的确认文字）和 `field`（确认值写入的请求体字段）。
