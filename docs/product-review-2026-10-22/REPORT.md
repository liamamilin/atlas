## 代码与数据流

- `app.tsx` 声明路由，`AppShell` 提供公共导航，页面经 Suspense 加载；`lang.tsx` 管理双语偏好。页面只维护交互状态，不直接写 SQLite。
- 正式类型：英文 applications 与持久翻译 JSONL → export/import → Atlas SQLite → gen-data → public/data → 首页、浏览、搜索、叶子。canonical API 提供当前正文；静态回退有对应检查。
- 项目/草稿/问答/设置：路由 → `lib/atlas.ts` → `drafts_api.py` → 对应 store/service。问答请求身份与轮询身份分开，避免跨对话覆盖。真实生成、执行与写回仍是显式操作，本轮不触发。
- 模板与案例：路由/组件 → `lib/factory.ts`、`factory-v1.ts` → 正式工厂 API → Scenario/CaseLibrary、制品、交接与预算服务。案例版本、冻结包和运行记录保留各自身份；静态通过不推导运行通过。
- URL 是工厂视图与案例选择的唯一导航依据。局部加载、错误、空状态与后台真实状态分开；失效或过时请求不能覆盖当前选择。

本轮不做大规模文件拆分、服务重写或新的生产调度平台。上述边界与现有正式服务保持兼容。
