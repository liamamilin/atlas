# HTTP 520 暂停与恢复

2026-10-24 11:04（上海时间）检查时，当前 100 叶子任务停在 `paused_model`，已完成 11 个叶子，累计处理 3,358 个候选，当前是第 12 个 `code-editor`。暂停发生于 2026-10-23 23:21，而非检查时仍持续运行。完整原始进度见 [BEFORE.json](BEFORE.json)。

## 原因与修复

Open Design 的两组请求均返回 HTTP 520，响应说明 Cloudflare 无法解析源站响应，并携带 `Retry-After: 60`。错误详情已记录，凭据未进入日志。

原有规则仅枚举部分 5xx 错误，遗漏 520，将其记为不可重试，第一次请求失败即暂停。这是本地重试分类的遗漏。

修复后 HTTP 5xx 服务端及网关错误统一进入已有的有界重试，不再依赖逐个状态码枚举。包含 520、522、524 和供应商自定义的 5xx。默认最多尝试三次（含首次）；遵守 60 秒的 `Retry-After`，仍不将网络故障误认为余额耗尽，原有认证及配额处理规则保留。

这次修复使 520 等错误进入自动重试；超过现有重试上限后仍会保存并暂停，不宣称任意持续故障下都能自行完成。
