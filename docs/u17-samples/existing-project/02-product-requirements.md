# 产品需求：Application Atlas 项目创建与切换入口

## 目标

用户无需先填写完整需求，只用项目名称、目标、模式和工作区即可建立 U17 项目；刷新或服务重启后可以重新选择它。

## 本版需求

### EP-R1 · 创建项目

表单收集名称、目标、新想法/已有项目模式和工作区。成功后返回 `prj_` 标识并成为当前选择。验收对应 EP-A1、EP-A4。

### EP-R2 · 列出与重新打开

项目列表显示名称、目标、模式、工作区和更新时间。重新启动本地服务后项目仍可读取。验收对应 EP-A2。

### EP-R3 · 以项目 ID 隔离上下文

前端当前选择只保存项目 ID；读取失败时显示项目不存在，不沿用另一个项目的资料或任务。验收对应 EP-A3。

### EP-R4 · 明确输入错误

缺少名称/目标/工作区、非法模式或不存在 ID 返回明确 4xx 和字段信息。失败不产生残缺项目，也不启动 agent。验收对应 EP-A4。

## 以后考虑

EP-R5 原生目录选择和工作区重新绑定等待 EP-U2。项目删除、归档和跨设备同步也不进入本轮。

EP-U1 保持开放：本轮可以先放置最小入口收集使用证据，不能把临时布局写成已确认产品决定。
