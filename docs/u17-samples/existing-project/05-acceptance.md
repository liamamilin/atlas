# 验收方案：Application Atlas 项目创建与切换入口

## EP-A1 · 创建与读取

提交完整新想法项目，确认响应 ID 以 `prj_` 开头；按该 ID 读取，名称、目标、模式和解析后的工作区一致。再创建已有项目模式，确认两类模式均保留。

## EP-A2 · 列表与重启

创建两个项目，记录 ID 和更新时间，停止并重启服务且使用同一项目库。确认两个项目仍按稳定顺序列出，字段未变化。

## EP-A3 · 项目选择隔离

在前端依次选择两个项目，确认每次重新向服务读取对应 ID。请求不存在 ID 时显示错误并清空无效选择，不展示前一个项目为当前项目。

## EP-A4 · 错误与原子性

分别提交缺少名称、空目标、非法模式、空工作区和格式错误 JSON；请求不存在项目。确认返回明确 4xx，项目总数不增加，后台没有创建 OpenCode 会话。

界面位置 EP-U1 和目录选择 EP-U2 不作为本轮通过条件；验收记录必须注明它们仍为开放或延期状态。
