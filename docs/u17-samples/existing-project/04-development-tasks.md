# 开发任务：Application Atlas 项目创建与切换入口

## EP-T1 · 补充项目列表查询和输入校验

覆盖 EP-R1、EP-R2、EP-R4。给 ProjectStore 增加稳定排序列表；定义名称、目标、模式和工作区校验。验证 EP-A1、EP-A2、EP-A4。

## EP-T2 · 增加项目 REST API

覆盖 EP-R1 至 EP-R4。增加三条路由和一致错误结构；使用临时项目库进行真实 HTTP 测试。验证 EP-A1、EP-A2、EP-A3、EP-A4。

## EP-T3 · 增加前端项目选择与创建入口

覆盖 EP-R1、EP-R2、EP-R3。增加类型、请求层、创建表单、列表和当前选择恢复；布局保留可调整性以处理 EP-U1。验证 EP-A1、EP-A2、EP-A3。

## EP-T4 · 验证重启持久化和项目隔离

覆盖 EP-R2、EP-R3、EP-R4。重启后端并重新读取同一临时数据库；创建两个项目并核对 ID 与字段不混用；执行非法输入用例。验证 EP-A2、EP-A3、EP-A4。

执行顺序：EP-T1 → EP-T2 → EP-T3 → EP-T4。EP-U2 和 EP-R5 不得在本轮以未验证的文件选择方案实现。
