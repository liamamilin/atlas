# 开发任务：本地优先的个人日计划器

## NI-T1 · 建立项目、候选任务与日计划数据模型

覆盖 NI-R1、NI-R3；实现迁移、稳定标识、跨项目关系校验和事务。验证 NI-A1、NI-A4。完成条件是两个项目的任务可进入同一天，重新打开数据库后关系不变。

## NI-T2 · 实现手动时间块与冲突计算

覆盖 NI-R2、NI-R4；实现时间块写接口、范围校验和纯冲突计算。验证 NI-A2、NI-A3。冲突测试同时覆盖重叠、边界相接、越界和删除后恢复。

## NI-T3 · 实现日计划界面与持久化恢复

覆盖 NI-R1、NI-R2、NI-R3；呈现候选任务、当天承诺、未排程项、时间块和冲突。验证 NI-A1、NI-A2、NI-A4。刷新和进程重启必须从持久化数据恢复。

执行顺序：NI-T1 → NI-T2 → NI-T3。NI-U1 在界面试点中收集证据；NI-U2 与 NI-R5 不得借本轮任务顺带实现。
