# 验收方案：本地优先的个人日计划器

## NI-A1 · 跨项目当天承诺

准备两个项目，各创建至少一个任务。把两个任务加入同一天，确认当天列表包含原 task ID；移除其中一个后原项目任务仍存在。

## NI-A2 · 手动时间块

为同一任务创建两个不重叠时间块，调整其中一个并删除另一个。确认显示顺序、持续时间和持久化记录与输入一致。

## NI-A3 · 冲突无副作用

创建重叠时间块和超出可用时段的时间块。确认响应指出对应 block ID 和原因；重新读取后开始/结束时间未被系统自动修改。边界相接不算重叠。

## NI-A4 · 重启恢复

记录项目、任务、当天选择和时间块 ID，停止并重新启动应用。确认所有 ID、字段和关系保持一致。

验收结果必须保存实际操作或自动测试证据。NI-U1、NI-U2 未解决不阻塞本版验收，但发布说明必须继续标明限制。
