## 2. 固定记录协议

每个案例开始前建立独立记录目录，建议使用 `docs/u17-pilots/<case-id>/`，至少包含：

- `manifest.json`：案例 ID、开始时间、模型及版本、Atlas 版本、来源 ID 与指纹、项目和工作区说明。
- `ordinary-input.md` 与 `ordinary-output.md`：不使用 Atlas 工作流约束的普通方案生成原始输入输出。
- `atlas-input.json` 与 `atlas-output.json`：Atlas 固定输入、运行 ID、原始模型结果、校验结果和重试原因；凭据不进入记录。
- `scope-and-timeline.md`：开始和结束口径、关键追问、范围确认、人工修改及耗时。
- `execution-and-acceptance.md`：文档版本、迭代、任务、执行、差异、验证命令、应用、产品验收和后续修改。
- `findings.md`：重要遗漏、错误建议、计划外修改、返工原因、严重度、处理结果和复验位置。

普通生成和 Atlas 生成使用相同模型、用户目标、项目材料及来源正文。两者允许使用不同的流程提示，因为结构化约束本身就是待评估方案；记录必须保存提示差异，不能把 Atlas 后续确认的需求反向加入普通生成输入。

统一记录以下观察项：

1. 首次结果是否通过现有结构和依据校验；失败时记录校验项、重试次数及新一轮是否改变了输入。
2. 用户或开发者指出的重要遗漏、无依据结论和错误建议。
3. 开发前仍需回答的问题，以及问题来自资料不足、需求未决还是实现约束。
4. 从固定初始目标到确认首个开发范围的耗时和主要修改原因。
5. 开发中的计划外改动、回退和返工原因。
6. Agent 报告、Atlas 文件与命令证据、结果应用和产品验收四种状态是否保持分离。

没有真实用户参与的观察项标为“未观察”，不能用开发者估计冒充用户结果。M5 先建立事实基线，不预设提升比例。

## 4. 案例二：已有项目改进

从一个包含真实说明、实现和回归命令的本地项目开始。优先选择当前 Application Atlas 的受控副本或另一个可以独立复验的小型真实项目；具体改进项必须来自现状检查，并在生成方案前固定用户可观察行为、允许写入范围和旧行为回归条件。

当前候选已固定为本地最小清单 CLI：项目 `prj_fdee487646e84eb08793d6304ff13f60`，只包含 `todo.py` 与 `test_todo.py`，基线回归为 6 项通过。本轮改进目标是安全持久化与损坏数据错误恢复，不新增任务命令，不改变既有字段语义；协议草案和固定输入见 `docs/u17-pilots/existing-project/`。普通生成对照完成前，不启动 Atlas 改进方案生成。

流程必须包含：

1. 建立工作区基线，区分文档声称、代码线索、运行证据与未检查范围。

4. 应用前制造一次相关外部变化，确认过期基线或冲突会阻止无提示覆盖；审阅并采用新基线后再继续。
5. 应用合规结果、记录独立产品验收，并从新基线创建下一轮。

## 6. 缺陷处理顺序

试点发现的问题按影响处理：

| 级别 | 判断 | 处理要求 |
|---|---|---|
| 阻塞 | 伪造或错引依据、自动改变确认范围、跨项目混用、覆盖外部修改、越界结果可应用、失败被标为验收通过、项目状态无法恢复 | 暂停对应案例，修复后从受影响步骤重跑；保留原始失败证据 |
| 重要 | 默认文档难以使用、需求与人工编辑关系不清、关键未知没有暴露、严格校验反复失败、开发任务缺少必要上下文 | 三个案例完成前修复，至少在一个受影响案例中复验 |
| 优化 | 文案、布局、非关键步骤数量、bundle 大小和更深的实例资料 | 记录实际影响，M5 收口后排序 |

隔离副本目前不复制 `node_modules` 和 `.venv`。每个代码案例在正式执行前记录依赖和验证命令可用性；若真实任务被阻塞，先评估项目级准备命令或受控的只读依赖复用，再决定是否扩大执行环境能力，不预先建设通用环境编排平台。

## 8. 后端演进决策

M5 完成后再更新长期执行架构：

- OpenCode 在代码执行、会话续作、恢复和权限控制上满足三个案例时，继续作为首个执行后端。
- 分析、文档生成或章节修改因结构约束产生明显重试和成本时，先评估这些边界明确的任务直接调用模型，再与 OpenCode 方案比较。
- 只有具体任务持续出现无法通过适配层解决的行为控制、部署、恢复或总成本问题时，才提出局部自研 agent 工具循环，并写明替代范围与长期维护成本。

完整自研 coding agent harness、多引擎产品化、云端执行和运行中长会话迁移不进入 M5 既定范围。
