# Open Design → OpenCode Go 自动切换验收

2026-10-23，按用户要求配置：主服务 Open Design，余额或配额耗尽时使用 OpenCode Go / `deepseek-v4.1-flash`。本机规则已启用，当前尚未触发实际余额耗尽，默认仍是 Open Design。

## 已完成行为

- 从供应商响应识别余额或额度耗尽，同一请求只切换一次。普通限流、认证和网络错误不触发额度切换。
- Go 使用官方入口及真实 Atlas 会话标识；旧 Go 地址自动迁移。Go 连接测试包含极小的真实模型调用，不以公开模型列表代替凭据验证。
- 激活状态保存到独立文件，不改写服务密钥；后续请求及进程重启后保持 Go。充值后可点击“重试主服务”。
- 记录实际 provider、model、切换原因及时间；缓存使用实际服务身份。
- 模型均不可用时暂停批量，保留已完成目标和已读来源缓存；恢复仅处理未完成项目，不创建被当作完成的元数据占位卡片。
- 设置展示当前备用规则；项目库展示暂停原因并提供继续按钮。历史项目和收藏不受影响。

## 实际请求

[DIRECT.json](DIRECT.json)：直接通过 Atlas 正常模型入口调用 Go 的 DeepSeek V4.1 Flash，返回有效 JSON `{"status":"ok","sum":5}`，约 2.43 秒，67 tokens。首次极短提示曾返回无效 JSON，保留在 [INITIAL.json](INITIAL.json)；这说明连通不等于格式必然正确，流程继续保留格式验证及有界重试。

[FAILOVER.json](FAILOVER.json)：仅在隔离测试中注入 Open Design HTTP 402 / `insufficient_balance`，Go 请求真实发送。两个请求的输入摘要一致，Go 返回正确 JSON，约 2.37 秒，88 tokens。再次调用相同输入命中 Go 缓存，无额外网络请求。这里模拟了主服务的额度耗尽，没有耗尽或改变真实 Open Design 余额。

[SERVICE.json](SERVICE.json)：确认无运行中的批量及生成任务后加载新 API。本机备用规则启用、尚未激活，目录项目数前后均为 153，凭据文件权限为 0600。
