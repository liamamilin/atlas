				90 text 一款 专注计时器 是一种将自主工作结构化为有意识的、定时专注时段的应用程序。用户承诺在一个有限的预期专注区间内工作；应用程序以可见的方式运行该区间，标记其结束，并通常过渡到休息阶段并记录已完成的会话。
			91 text 它解决了一个具体问题：在充满干扰的环境中开始并维持对单一工作的注意力。这种模式源自限时注意力方法——最突出的是番茄工作法，其中工作被分解为以短暂休息分隔的定时区间。
			92 text 边界界定：专注计时器不是用于任意事件的秒表（那是时钟/计时器工具），不是花费时间的账本（时间追踪），不是未来区间的计划（时间块），也不是任务系统（待办事项列表）——尽管它触及了所有这些方面。
			93 text 其定义核心很小：
			94 text 专注会话 — 一个有意识的、有限的预期专注区间
└── 由用户启动
     └── 由应用程序可见地运行
         └── 完成，或放弃

			95 text 通常与该类型关联的其他所有内容——工作/休息循环、统计数据、任务列表、屏蔽、游戏化——在当前产品中很普遍，但可移除：存在不包含其中任何一项的产品，且起源方法的纸笔和厨房计时器实现完全没有任何这些功能。

					254 text Overview
				255 container
					256 text A  Focus Timer  is an application that structures self-directed work into deliberate, timed sessions of focused attention. The user commits to a bounded interval of intended focus; the application runs the interval visibly, marks its end, and commonly transitions into a break and records the completed session.
				257 text It addresses a specific problem: starting and sustaining attention on a single piece of work in an interruption-rich environment. The pattern descends from timeboxed attention methods — most prominently the Pomodoro Technique, in which work is broken into timed intervals separated by short breaks.
				258 text The boundary: a focus timer is not a stopwatch for arbitrary events (that is the Clock / Timer utility), not a ledger of time spent (Time Tracking), not a plan of future intervals (Time Blocking), and not a task system (To-do List) — though it touches all of these.
				259 text The defining core is small:
				260 text Focus session — a deliberate, bounded interval of intended focus
└── started by the user
    └── run visibly by the application
        └── completed, or given up

				261 text Everything else commonly associated with the Type — the work/break cycle, statistics, task lists, blocking, gamification — is widespread in current products but removable: products exist without each of them, and the origin method's paper-and-kitchen-timer realization had none of them at all.
				262 heading Users & Context, Value: 2
					263 text Users & Context
				264 text The primary user is an individual doing self-directed knowledge work or study — writing, coding, reading, exam preparation, problem sets — who wants external structure for attention: a commitment device that says "work on this now, until the timer ends."
				265 text Typical setting: a desk or study environment with the phone or computer in reach. Sessions are short by design and repeated through a work period.
				266 text Secondary motivations observed in the market: reclaiming attention from the phone (digital-detox positioning), structure for users who describe attention difficulties (ADHD-friendly positioning), and shared focus for study groups or teams.

						274 text Focus session  — the central object: one bounded interval dedicated to one intention ("work on X until the timer ends"). The user starts it; the application times it visibly and continuously (a countdown toward a completion signal is the classic form); it ends by completion or by being given up. One session is one unit of focused work.

						277 text Attention framing  — the session exists for focused work or study. This purpose separates the Type from a generic timer utility: the timing is bound to work-attention semantics (sessions, breaks, focus), not to arbitrary events such as cooking or parking.
				278 text If the timed session disappears, the product is a planner or task list. If the attention framing disappears, it is a clock utility. Both removals destroy the Type; nothing else does.
