# 调研源码外置存储

用户要求将调研用上游项目源码放到 `/Volumes/个人资料/2026/altlas源码`，模板仍留在本项目。

迁移范围仅为正式工厂 `application-atlas-production-pack/atlas/template-factory/sources/` 缓存。模板、标准开发包、模型原始返回、固定来源快照 JSON、研究证据、六个示例应用及用户数据库均不迁走。

原 sources 入口保留顶层目录符号链接，指向上述外置目录。固定来源记录继续通过原绝对路径访问，JSON、commit 和文件摘要不改写。仅允许宿主 sources 这一个入口指向外部目录；案例入库仍验证各固定文件摘要，并拒绝任意外部路径和内层符号链接。

迁移流程：正式暂停新派发 → 在途调用自然结束 → 完整复制并逐文件校验 → 原 sources 改为兼容链接 → 再次逐文件校验与历史来源验证 → 删除已核验的本地备份 → 对应源码 CI 与正式 host revision → 同一队列恢复。失败保留本地副本，不修改账本或凭空补调。

运行时需挂载个人资料外置盘。若 sources 链接断开，宿主以 source_storage_unavailable 暂停，不能在内置盘重新建立同名缓存。挂载原盘、核对链接目标及文件摘要后，使用原计划正式 resume/start；不新建计划、不重置调用或窗口。

模型阅读所需的受限工作区副本及原始调用证据仍留在工作目录；不移动或重写已经摘要绑定的调用材料。原始来源缓存和后续下载写外置盘。

状态命令与首轮操作沿用 full-leaf-auxiliary-2026-10-21/OPERATIONS.md 及最新 source-network-isolation 报告；本轮不增加模型调用额度，不开启第二轮。
