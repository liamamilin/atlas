本文件记录本实现实际采用的默认值与理由、被否方案、明确排除的范围，以及仍需
人类决定的问题。范围来自 `source/REQUEST.md`、`source/CONTRACT.md` 与

后者为已确认的 P0 范围。

## 本次修复（repair attempt 1）

- **观察到的失败**：以 `python3 -B app.py --port <port> --data-dir <dir>` 启动时，
  进程在绑定端口前即以退出码 1 结束：`api.py` 中 `make_handler` -> `Handler`
  类体执行 `store = store`，抛 `NameError: name 'store' is not defined`。
- **根因**：类体是独立作用域。`store = store` 中的赋值会把 `store` 标记为类体
  局部名，右值不再回退到外层函数参数，因此定义类时即失败。`static_dir` 同理。
- **修复**：删除类体内的 `store = store` / `static_dir = static_dir`，改为在类
  定义完成后用 `Handler.store = store` / `Handler.static_dir = static_dir` 注入。
  方法仍通过 `self.store` / `self.static_dir` 读取，行为不变。
- **未改变**：数据路径（`<data-dir>/budget.sqlite3`）、静态资源目录、路由、
  校验规则、金额“分”存储、CSV 方言、UI 测试钩子全部保留；未新增依赖或范围。
- **自检状态**：本次修复未运行任何程序（作者不得执行），全部检查为 not_run。

## 实际采用的默认值

### D01 金额表示与取整（采用）
以整数“分”存储与计算，响应渲染为两位小数字符串；超过两位小数或非正数直接
拒绝，绝不静默取整或裁剪。
理由：避免二进制浮点误差；满足“不静默取整或裁剪输入”。
代价：`1.2300`、`10.000` 之类的等价输入会被拒绝；用户需按两位小数录入。
可逆：如用户要求自动舍入到分，改 `money.parse_positive_amount` 的指数检查即可。

### D02 超支不跨月结转（采用）
仅在当月显示负剩余，不自动结转下月。
理由：已确认验收只承诺当月计划 / 实际 / 剩余；跨月 rollover 属成熟扩展。
可逆：汇总公式与月切换展示是唯一改动点。

### D03 SQLite 单库 + 事务写入（采用）
单文件 `<data-dir>/budget.sqlite3`，每次写入在事务中提交，只写 `--data-dir`。
理由：单机集中持久化、崩溃后仍可恢复，满足“数据只存指定目录、重启保留”。
替代：JSON 文件全量重写——被否，并发与部分写入风险更高，且需要自建原子替换。
可逆：存储层集中在 `db.py`。

### D04 无完整编辑历史（本实现不建，仍待人类确认）
P0 以导出 CSV 作为最小审计 / 恢复起点，不建历史表。
状态：**待人类确认**（见文末）。

### D05 CSV 方言（已定）
UTF-8、RFC 4180 引号规则、`QUOTE_MINIMAL`、CRLF、表头
`date,category,amount,note`。依据标准库 `csv` 与 CONTRACT，不发明 Excel 专有行为
（如公式转义）。导出由 `api.py:_serve_export` 与 `db.export_rows` 实现。

### D06 不支持删除分类（采用）
未使用分类保留可见，契约未定义分类删除语义。
替代：级联删除分类及其支出——被否，会破坏历史一致性与“未使用分类仍可见”的要求。
可逆（后续阶段）。

## 其他实现默认

- **HTTP 层**：标准库 `ThreadingHTTPServer` + `BaseHTTPRequestHandler`，只绑定
  `127.0.0.1`。被否：Flask/FastAPI（第三方依赖，违反零安装）。
- **持久化边界**：数据库路径固定为 `<data-dir>/budget.sqlite3`，应用目录只读；
  不写日志文件到应用目录。
- **ID 校验**：路径中的 `{id}` 必须为正整数，否则返回非 2xx JSON，而非 HTML 500。
  兜底 `except Exception` 也返回 JSON，确保任何失败路径都不是 HTML 错误页。
- **同月同名**：先查重再插入，并由 `UNIQUE(month,name)` 兜底，避免产生隐藏的第二条分类。
- **金额校验失败**：在解析阶段就返回错误，数据库不变，因此失败的请求不会污染状态。
- **UI 状态源**：页面通过 `fetch` 读取 `/api/state`，不内嵌服务端渲染的 JSON 状态，
  以避免页面默认月份与被查月份不一致。前端与 JSON API 共用同一真实状态。
- **反馈区域**：`#feedback[aria-live=polite]` 展示成功 / 失败提示（如重复分类、
  非法金额、日期跨月）。
- **未复制第三方代码**：仅使用 Python 标准库与自写前端。被否：复用 Actual Budget
  （NodeJS，规模不匹配）或 Firefly III（AGPL-3.0，强 copyleft）。

## 明确排除（不在 P0）

- 银行 / 支付连接、账户体系、多用户、同步、多租户——超出“单个本地用户”范围。
- 多币种与自定义符号——货币固定人民币。
- 跨月结转、预算模板、常用分类——成熟扩展，未获授权。
- 完整编辑历史 / 审计日志——见 D04，尚未确认。
- 分类删除 / 归档 / 重命名——见 D06。
- Excel 本地化 / 分隔符 / 编码变体。
- 任何测试期专用端点或硬编码业务夹具：验收材料是外部检查器，不属于应用本身。
