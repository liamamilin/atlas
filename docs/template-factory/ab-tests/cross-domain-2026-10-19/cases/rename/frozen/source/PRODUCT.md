# 产品定义

下载目录的预览式批量重命名与撤销

只整理一个明确指定本地目录的用户

先预览单目录文件名的文字替换，再明确确认执行，并能撤销这次批量改名；保护原始内容和未选文件。

1. 列出指定目录的真实普通文件
2. 输入文字查找与替换，输出旧名到新名的计划
3. 预览不改动原文件，用户确认后执行计划
4. 查看执行回执和当前文件名
5. 撤销这次执行并核对文件名与内容恢复

- Python 标准库 CLI，默认不递归；不处理目录和符号链接，不接触指定根目录外的文件
- 查找为非空字面文本，不是正则；新名字必须是单个文件名，不允许目录穿越
- 冲突或目标已存在时拒绝整份计划，不覆盖、不静默跳过后说全部成功
- 预览与执行间源文件内容被改动须拒绝过期计划；失败后旧数据不能丢失
- 执行及撤销均须显式 --confirm，重复执行不得产生第二轮重命名；撤销遇新冲突也不能覆盖
- 演示只使用测试创建的普通文件，不对用户真实下载目录运行

- R01 目录整理用户: 在一个明确指定的本地根目录上运行 `python3 app.py --root DIR COMMAND ...`：先 list 查看立即普通文件，再对单目录文件名做非空字面查找/替换以生成旧名到新名的计划，显式 --confirm 执行并查看逐条回执，最后显式 --confirm 撤销本次批量改名并核对文件名与内容恢复；只希望对根目录内普通文件操作，不触碰目录、符号链接与根目录外文件。
- R02 独立验收操作者: 提供一份新隔离的 app.py 与一次性根目录夹具，按 acceptance/README.md 运行 acceptance/run.py 并据退出码判定 A01-A12 行为；生成阶段所有状态记为 not_run，由其在不执行/不安装受限的受控环境执行并自行记录结果。
- R03 开发者: 仅编写受控范围内的应用与验收程序，不执行、不安装、不调用 shell/子进程（验收程序自身对被测应用使用的 shell=False 子进程除外）；如实验收记为 not_run，绝不伪造通过报告、硬编码夹具或复制第三方代码。
