# 产品定义

个人月度预算与消费前剩余额度

单个本地用户，不连接银行或支付服务

按月为用途设置预算，记录和纠正实际支出，在消费前看到准确的计划、已花和剩余，并导出自己的记录。

1. 选择月份并建立分类及预算
2. 记录有日期、分类、金额和备注的支出
3. 核对分类及整月计划/实际/剩余，超支可见
4. 修改或删除误记支出并即时重算
5. 切换月份、重启后仍可回查
6. 导出当月支出 CSV

- 仅本人本地数据；货币为人民币，两位小数，支出须为正数，不静默取整或裁剪输入
- 每月预算及支出互相隔离；未使用分类仍可见，超支显示负剩余，不自动阻止记账
- 修改/删除后汇总与列表一致，失败输入给出反馈且不破坏旧数据
- 数据只存指定目录，正常重启保留；导出对应当前月份，中文、引号和换行可往返

- R01 本地使用者（唯一用户）: 在本地浏览器中选择月份、建立分类与月预算、记录/修改/删除支出、查看计划/实际/剩余（含超支负剩余）并导出当月 CSV；数据仅存于指定目录，全离线、无银行或支付连接。
- R02 独立验收操作员: 在隔离环境中以显式目标（--target-url，或 --app-path 加 --data-root）运行 acceptance/run.py，针对真实实例执行行为断言并读取非零退出码；不接触真实用户数据、凭据或外部网络。
