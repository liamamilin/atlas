# 社区共享设施的预约与取消

用户：一个设施管理员和封闭名单内的两个居民

目标：管理员配置设施，居民登录后选择时段预约、查看自己的预约并取消；同一设施不能被重复占用，权限由服务端执行。

流程：
- 通过本地演示账号登录
- 管理员创建可预约设施
- 居民查看设施及占用时段，提交开始与结束时间
- 居民查看和取消自己的预约，管理员可管理全部
- 取消保留状态记录并释放原时段
- 刷新及真实重启后仍一致

已确定范围与规则：
- 仅回环本地演示，不集成邮件、真实住户、支付或公网身份服务
- 管理员与居民角色不可由请求参数伪造；居民不能创建设施、查看别人预约详情或取消别人的记录
- 结束必须晚于开始；时段为有时区的 ISO8601，按真实时刻比较；半开区间相邻可预约、重叠不可预约
- 并发竞争同一设施重叠时段最多成功一笔；不同设施不互相阻塞
- 取消可重复提交但不能破坏历史或别人的数据；失败要说明原因，不伪报成功
