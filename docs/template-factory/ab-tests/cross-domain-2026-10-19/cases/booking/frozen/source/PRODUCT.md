# 产品定义

社区共享设施的预约与取消

一个设施管理员和封闭名单内的两个居民

管理员配置设施，居民登录后选择时段预约、查看自己的预约并取消；同一设施不能被重复占用，权限由服务端执行。

1. 通过本地演示账号登录
2. 管理员创建可预约设施
3. 居民查看设施及占用时段，提交开始与结束时间
4. 居民查看和取消自己的预约，管理员可管理全部
5. 取消保留状态记录并释放原时段
6. 刷新及真实重启后仍一致

- 仅回环本地演示，不集成邮件、真实住户、支付或公网身份服务
- 管理员与居民角色不可由请求参数伪造；居民不能创建设施、查看别人预约详情或取消别人的记录
- 结束必须晚于开始；时段为有时区的 ISO8601，按真实时刻比较；半开区间相邻可预约、重叠不可预约
- 并发竞争同一设施重叠时段最多成功一笔；不同设施不互相阻塞
- 取消可重复提交但不能破坏历史或别人的数据；失败要说明原因，不伪报成功

- R01 设施管理员: 配置可预约设施；查看并管理全部预约（含他人）；可取消任意预约；其权限完全来自服务端账户角色，不信任请求参数。
- R02 居民: 登录后查看设施与占用时段，提交、查看并取消自己的预约；不能创建设施、不能查看或取消他人记录。
