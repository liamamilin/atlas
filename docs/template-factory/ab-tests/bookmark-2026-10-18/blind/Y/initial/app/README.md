# 生活待购与灵感收藏夹

本地单实例的个人书签库：把随手看到、暂时不处理的外部网页链接先存起来，
按简单归类整理，日后通过关键字或归类找回，并一键跳回原页面。

本应用只使用 Python 3 标准库与 `sqlite3`，没有第三方依赖，没有构建步骤，
不在服务端发起任何出站请求（不抓取标题、描述或图标）。

## 启动

```bash
python3 app.py --port 3000 --data-dir ./data
```

- 只绑定 `127.0.0.1`，不接受外部网络访问。
- `--port`：监听端口（默认 3000）。
- `--data-dir`：所有持久数据的目录（默认当前目录下的 `data`）。
- 可选参数：`--public-origin`、`--public-base-path`（也可用环境变量
  `PUBLIC_ORIGIN`、`PUBLIC_BASE_PATH`）、`--stage`（默认 `P2`）。

启动后打开 `http://127.0.0.1:3000/`。

## 存储位置

- 数据只写入 `--data-dir` 指定的目录，主文件为 `bookmarks.sqlite3`（WAL 模式）。
- 备份请在停写后复制整个数据目录，或使用 SQLite 的 backup API；
  直接热拷贝数据库文件不具备事务安全性。
- 删除数据目录即可完全重置（会丢失全部收藏）。

## 已实现的范围

- 保存链接：URL 必填；标题可留空（由主机名派生）或手填；备注可选。
- 单一归属归类：一条记录恰好属于一个归类；未指定时进入默认归类「未分类」。
- 新建 / 重命名归类；在保存时选择归类；之后可移动记录。
- 删除归类时显式二选一：把其中记录移入目标归类，或经确认后把记录送入回收站
  （归类行只做 tombstone，不物理删除；默认归类不可改名或删除）。
- 重复 URL 默认阻止并给出既有记录链接，可选择「仍然保存一份」。
- 打开记录：`GET /b/{id}` 以 302 跳转到保存时记录的原始 URL。
- 软删除、回收站浏览、恢复（回原归类或指定归类）、单条永久删除、清空回收站。
- 编辑标题与备注。
- 关键字检索（标题 / URL / 备注，NFKC、大小写不敏感）与按归类浏览，
  支持最新 / 最早排序与分页。
- JSON API：`/api/health`、`/api/bookmarks`、`/api/categories`、`/api/trash` 等。

## 明确不做

- 不做账号、登录、多用户、协作与公开分享；本机读取未认证，
  回环监听不等于认证。
- 不做服务端抓取标题 / 描述 / 图标，不做网页快照、截图或 PDF 副本。
- 不做正文全文检索、失效链接扫描、批量操作、浏览器扩展与导入导出。
- 不引入任何第三方依赖、遥测或外部资源。
- 不承诺性能、并发写入与真实第三方站点的可达性。

## 限界

- 单条 URL 最长 2048 码点；标题 500；备注 10000；归类名 80；请求体上限 64 KiB。
- 归类行删除后只保留 tombstone，长期使用会累积少量已删归类行，名称可复用。
- 回收站不过期，由用户手动清空；清空是实例级破坏性操作。
- 数据保存在本机单一实例，不承诺多实例共享同一个 SQLite 文件。
- 打开链接时返回的 302 地址是保存 URL 的 WHATWG 序列化 ASCII 形式，
  与原始输入的 Unicode 形式不保证逐字符相同（例如 IDN 会转为 punycode）。
