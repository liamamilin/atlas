# 生活待购与灵感收藏夹

一个在本机运行的私人收藏夹：把浏览时随手看到、但当下不处理的网页链接先存下来，
选一个简单归类，之后需要时再回来检索、打开或移动到更合适的归类。

## 启动方式

```
python3 app.py --port 8000 --data-dir ./data
```

- `--port`：监听端口，仅绑定 `127.0.0.1`（不对外网开放）。
- `--data-dir`：数据目录，所有收藏数据都写入这里。
- 启动后用浏览器打开 `http://127.0.0.1:8000/`。
- 停止：在终端按 `Ctrl+C`。

只依赖 Python 3 标准库与内置 `sqlite3`，无需安装任何依赖或构建步骤。

## 数据存放位置

数据库文件为 `<data-dir>/bookmarks.db`（SQLite）。关闭页面或重启进程后数据依然保留，
再次以相同 `--data-dir` 启动即可看到原有内容。删除该目录即清空全部收藏。

## 已实现的功能

- **保存链接**：填写网页地址（可自动补全 `https://`）、可选标题与备注，并选择一个归类。
- **归类**：内置默认归类「未整理」，首次启动还会建立「待购」「家居改造」「以后看看」三个示例归类；
  可随时新建、改名、删除归类。删除归类时，其中的记录会自动移动到默认归类，不会丢失。
- **移动记录**：通过记录的「编辑 / 移动」修改归类、标题、地址与备注。
- **检索**：顶部搜索框按关键字匹配地址、标题、备注与归类名称；左侧按归类浏览。
- **打开原网页**：点击记录标题会经 `/open/<id>` 跳转到原始网址，并记录打开次数与最近打开时间。
- **删除记录**：单条删除（带二次确认）。
- **排序**：可在「最近保存在前 / 最早保存在前」之间切换。

## 适用范围与限制

- 单机、单用户使用；没有账号、云同步或协作功能。
- 不抓取网页内容，标题需自行填写（留空时用链接中的文件名或域名代替）。
- 仅支持 `http` / `https` 链接。
- 数据以明文 SQLite 文件保存，未做加密；请自行备份 `bookmarks.db`。
- 界面为中文，未做多语言适配。
