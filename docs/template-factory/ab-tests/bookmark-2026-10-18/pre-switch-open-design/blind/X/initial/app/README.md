# 拾光夹

一个中文个人生活待购与灵感收藏夹，用于先存下偶然遇到的网页，之后再按归类浏览、检索和打开。仅使用 Python 3 标准库与 SQLite，无需安装依赖或构建。

## 启动

要求 Python 3.9 或更新版本。在源码目录执行：

    python3 app.py --port 8765 --data-dir ./bookmark-data

然后访问 http://127.0.0.1:8765 。服务只绑定 127.0.0.1，不会对局域网开放。

## 数据存储

所有持久化业务数据都位于启动参数指定的数据目录内：`<data-dir>/library.sqlite3`。SQLite 的 WAL 模式可能在同一目录产生 `library.sqlite3-wal` 和 `library.sqlite3-shm`。停止服务后复制这些文件即可备份；删除数据目录会清空全部收藏。应用不会把业务数据写到其他目录。

## 实际功能

- 保存网页链接，缺少协议时自动补 https；可填写标题和备注，标题留空时使用网址生成。
- 首次启动自带「待购」「家居改造」「以后看看」三个归类，新链接默认进入「待购」。
- 新建、改名、删除归类；删除归类时其中记录会迁移到默认归类，最后一个归类不能删除。
- 编辑标题和备注，把记录移动到其他归类，或永久删除记录。
- 按归类浏览，按标题、网址或备注做关键字搜索。
- 在新标签页打开原网页；所有页面为中文响应式界面。
- 数据保存在 SQLite 中，关闭进程后重新启动仍然存在。

## 范围与限制

- 单机单用户，无账号、权限、协作、云同步或远程访问。
- 不自动抓取网页标题、封面或图标，不检查链接是否仍可访问；打开原网页需要联网。
- 删除记录没有回收站，无法撤销；删除归类会迁移记录而不是删除它们。
- 搜索为 SQLite 子串匹配，不提供拼音、分词、排序权重或全文索引。
- 不支持导入导出、批量编辑、归类排序和浏览器扩展。
- 服务使用明文 HTTP，仅适合本机回环地址；请勿改为对外监听。
- 本次交付未实际启动服务或运行自动化检查。
