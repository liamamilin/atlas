# 认知包工厂接入与验证

日期：2026-10-17。已完成范围：具体认知模板作为独立制品进入工厂，完成结构校验、冻结、阅读和开发交接。没有调用新的 provider，没有修改旧制品或既有场景，没有执行发布。

## 可实际使用的路径

模板工厂 → 模板制品 → 载入书签认知样板（或导入兼容 ZIP）→ 查看认知内容 → 选择章节/查看能力、来源和决策 → 填写项目名称与阶段 → 创建开发包 → 下载。

- 使用 `atlas.product-blueprint.v0`、显式 `product-blueprint` 类型；缺少类型的历史制品仍按 `runnable-starter` 处理。
- 校验必需文档、固定场景、来源/能力/阶段/验收的双向引用、决策、测试程序文件、计划一致性及完整文件摘要。程序存在与结构通过不证明程序能执行或产品定义合理。
- ZIP 先检查全部路径、重复项、特殊文件、大小，再读取；沿用原秘密文件和上游 agent 配置禁入规则。只允许包内已声明 `AGENT.md` 作为内容保留，不执行指令。
- 导入内容不调用模型、不运行 build.py/verify.py/测试脚本；输入场景保持包内历史快照，不新增或确认本地场景。相同包重复/并发导入复用同一制品。
- 认知包保留为冻结候选，不直接复用源码模板的审阅、runtime、修订、等级或发布操作。旧 API/store 调用入口均有类型保护。包内历史报告只作为声明保留。
- 正文按 Markdown 排版，HTML 不执行，图片不自动加载；相对文件引用显示为文本，外部 HTTP(S) 资料链接需主动打开。
- 开发包把原包放在 `blueprint/`，外层加入 README、AGENT、PROJECT_DECISIONS.json 和 `.atlas-blueprint.json`；项目名称/阶段/选择不修改原包。它是开发交接，不是已实现的应用。
- 冻结 ZIP 根目录保留原始认知协议，可再次导入；开发包有独立下载文件名，原应用下载接口行为保持。
