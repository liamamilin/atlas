# 默认值与人工决策

这些是可调整的样板默认；先尊重当前项目已经确认的决定。普通可逆选择按默认推进并记录，只有依赖核心取舍的阶段才停下来问人。

## D01 · 部署与数据归属

默认：单人本地浏览器库

何时询问：采用样板时可先用此默认；如要求云同步、登录或多人共享，在相关阶段实现前问人。

影响：改为托管会引入后端、账户、权限、同步和迁移需求。

状态：样板默认，可调整

## D02 · 默认技术栈

默认：原生 HTML/ES modules + IndexedDB；静态本地预览

何时询问：可逆的样板默认，无须为它推翻现有项目；采用现有框架时保留行为契约。

影响：轻依赖便于检验认知交付；不是其他产品必须使用的技术栈。

状态：样板默认，可调整

## D03 · URL 与重复记录

默认：仅允许绝对 http/https，无凭据；保留 query/hash，使用 URL.href 规范化；P2 只提示重复

何时询问：没有得到用户选择前不自动去参数、合并或删除。

影响：去跟踪参数可能改变资源含义，属于待验证取舍。

状态：样板默认，可调整

## D04 · 归类模型

默认：单层字符串，空白归到“收件箱”；输入新值即创建归类

何时询问：默认可逆；新增多级分类先调整数据与验收。

影响：改分类修改同一 id，不能创建替代副本。

状态：样板默认，可调整

## D05 · 成功与失败

默认：写事务 complete 后才显示“已保存”；失败保留输入并显示 alert

何时询问：首阶段完整性要求，不允许为让测试通过降级。

影响：不得只监听单个 put 成功事件。

状态：样板默认，可调整

## D06 · 删除与导入

默认：P1 软删除；JSON atlas-bookmarks/1；导入按 id 仅新增，冲突保留原值并报告；整批验证后单事务写入

何时询问：需要永久删除、覆盖或替换整个库时先问人，不能由默认值代替授权。

影响：导出全部记录含回收站，不受筛选影响。

状态：样板默认，可调整

## D07 · 服务端抓取与外部服务

默认：默认不抓标题、favicon 或正文，不接分析、支付和外部 API

何时询问：接入需要用户决定目标服务和数据范围。

影响：避免在保存私人链接时无意外发。

状态：样板默认，可调整

## D08 · 运营与商业化

默认：当前单人版本不实现计费、成员后台和全量审计

何时询问：改为商业托管前重新评估，不能声称当前版本已经支持。

影响：需补套餐、取消退款、支持流程、管理权限和审计范围。

状态：样板默认，可调整
