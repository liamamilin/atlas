# 产品定义

生活待购与灵感收藏夹

目标用户：习惯先把感兴趣的网页存起来、之后再回头处理的普通网络用户

目标：把偶然看到但当下不处理的外部网页链接留存，日后需要时能重新找到并回到原页面

## 核心流程

1. 用户在浏览时看到想记住的商品页、教程或灵感图片，主动保存该链接
2. 保存时选择一个简单归类，如“待购”“家居改造”或“以后看看”
3. 未经整理的链接可先进入默认归类，之后再手动移动到更合适的位置
4. 用户在需要实际处理时打开个人库，浏览或检索相关归类
5. 用户从记录打开链接，回到原始网页继续购买、阅读或参考

## 场景原始验收

- 用户主动保存的链接在多次会话之间持久保留，形成不断增长的个人收藏
- 每条记录都以 URL 锚定到外部网页，打开记录即跳转到该页面
- 用户可以在归类之间移动记录或新建归类，操作结果在重新打开后仍然有效
- 通过归类浏览或关键字检索，用户能找到此前存入的特定链接

## 角色

- R01 个人收藏者：保存、整理、检索、导出自己的收藏；没有其他成员或运营管理员的隐含权限。

## 首阶段异常与非功能要求

输入可能是危险 URL 或带 HTML 的标题；存储可能不可用或写入失败；保存期间可能重复提交；搜索可能为空；外链会离开本应用。必须给可理解的错误与状态，失败不清空输入、不谎报成功、不破坏已有记录。默认不因保存而访问外站。键盘、标签、状态播报和窄屏首阶段就需要。当前没有真实容量/性能基准，不捏造 SLA；P1 前仅适合可接受本地存储风险的试用，不称为已具备完整备份恢复的成熟产品。
