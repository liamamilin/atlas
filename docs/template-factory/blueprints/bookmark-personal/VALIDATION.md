# 样板验证状态

日期：2026-10-17。认知包版本：0.1.1。首个样板的独立审阅、下游 P0 开发试用与真实浏览器验收已完成；未发布模板。

## 实际结果

- 包含 18 项能力、8 个默认决策、三个阶段和 17 个用例。结构、引用/阶段/用例映射与完整性校验通过；它们不代替语义判断。
- OpenCode 同一已授权 provider/model 的独立会话：一轮完整审阅、两轮修订复审；前两轮要求修改，第三轮确认剩余 A05/A06 问题闭合。第三轮是定向复审，并非重新全面审计；所有审阅均为静态审阅，未运行应用。
- 修订包含保存时外部请求检查、真实成功状态、新建/编辑危险输入与输入保留、已有库读取故障、浏览器持久 profile 重启；也补强 P1/P2 删除持久化、混合导入、冲突数量和单事务断言。
- 新开发会话仅依据认知包生成 P0 应用，实际使用 IndexedDB。没有复制上游完整应用，也没有修改生成应用源码来适配结果。开发会话读取 0.1.0；审阅后用 0.1.1 的补强验收验证同一实现，不能称为完整 0.1.1 包的另一次全新开发试验。
- 真实 Chromium 对目标运行 P0 十项，全部通过：A01–A09、A17。包含保存/编辑/分类/搜索/返回原网页、跨浏览器重启、危险 URL 与 HTML、打开/读取/写入故障、重复提交、键盘与 375px 布局。
- 对同一应用故意取消提交，A01 确实失败且退出 1；这是验收工具负向对照，不是产品失败或额外的产品通过项。
- 参考 URL/IndexedDB 原子写模块实测通过；故意不工作的临时目标自检通过。模块验证、工具验证、独立审阅、应用验收分别记录。
- 人工浏览器复查：保存合成链接、自定义分类、编辑改分类、按分类文本搜索、刷新后保留。截图和试用代码保存在仓库的对应 pilot 目录。

## 本地复查

在包根运行 `python3 build.py`、`python3 verify.py`。测试依赖按 acceptance/README.md 安装。启动独立试用应用后运行 `node acceptance/run.cjs --base-url http://127.0.0.1:5220 --phase P0 --out /tmp/bookmark-P0.json`。本仓库可用 `NODE_PATH="$PWD/atlas-web/node_modules"` 复用 Playwright 1.63.0。每例使用全新合成数据，只有 A04 明确点击外链产生一次被阻断的目标导航；网络观察覆盖用例操作及 100ms 结束窗口，不证明任意延时或所有网络侧信道。
