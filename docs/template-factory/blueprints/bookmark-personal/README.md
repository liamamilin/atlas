# 生活待购与灵感收藏夹：个人本地认知模板

这是 Atlas 首份认知模板样板，不是已经完成全部功能的应用源码包，也尚未接入工厂的新产物发布流程。规范版本 0.1.1。

## 从哪里开始

1. 阅读 PRODUCT.md 和 DECISIONS.md，确认当前项目适用默认单人本地形态。
2. 让 coding agent 阅读 AGENT.md、ARCHITECTURE.md 和 ROADMAP.md，只实现当前阶段。
3. 按 acceptance/README.md 安装测试工具，运行真实目标的对应验收并保存结果。
4. 用 template.json 核对需求和用例映射；更新决策与证据，不随意删除失败用例。

CATEGORY.md 给出处和复用判断；references/ 中只有新编写的小模块，无第三方应用源码。实际验证与待执行事项见 VALIDATION.md，不能由文档存在推断应用已通过。

## 样板校验与打包

`python3 build.py` 根据 template.json 生成阅读文档；`python3 verify.py` 校验规范、映射、文件摘要。规范包含验收 ID 与阶段，测试程序需要逐项有对应执行器。

## 交付边界

- 首阶段通过不代表 P1/P2 完成。
- 在线资料未固定源码 commit 的项目仅用于能力研究。
- 样板不包含任何第三方应用源码；当前开源许可记录不是法律意见。
- 尚未接入工厂的新类型生产、发布或页面下载流程。
- 默认值、接口名称和阶段划分可以因项目改变，但必须同时更新决策、契约和验收，不可只改测试令其变绿。
