# 按轮次执行辅助模板生产

保留同一计划和所有历史。改动限定于现有服务、协调者及其回归测试，不建设额外调度平台。

1. `pilot_complete`：固定原电子书库、Markdown 编辑器、资源日历三叶子，复用研究与首轮交付，执行既有 attempt-2 内容修订和独立审阅。每叶子累计最多六次、不重复付费启动。
2. `full_first_round`：正式绑定原冻结范围全部 1805 叶子；已有模板复用、已处理项保留、剩余首轮逐批 20 项并发二接续。内容修订 lane 在预算预留时拒绝，防止第一轮自动混入第二轮。
3. 单叶子内容、生成、交付与下载失败保留工作目录及失败记录，继续其他叶子；数据库、输入完整性、总额度、磁盘或真实共享故障保留原安全停止机制。
4. 每轮结束生成 `ROUND_REPORT.json` 及不可覆盖的时间戳快照，列出每叶子状态、失败阶段/代码/原因、证据工作目录与可用制品。首轮结束暂停，待集中分析。

必要验证：有界小批次包含修订轮、全量首轮只跑 first lane；41 项按 20/20/1 接续、失败不阻断、修订不混入首轮；数据库故障仍暂停；轮次范围绑定、授权摘要、幂等、并发 drain 与累计预算不变；日历/订阅阅读已通过检查点继续保留。实际模型结果与 fixture 分别报告。

源码检查与精确提交 CI 通过后，追加原宿主版本记录，再通过 `workflow-round --evidence REQUEST.json` 正式激活及 `start` 启动已有 launchd。全量运行后不实时人工跟随；用持久状态和报告查询。原保护文件与历史独审、失败、授权均保留。
