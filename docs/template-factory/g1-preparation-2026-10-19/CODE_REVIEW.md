# 独立实现审查

独立 Sol reviewer 以当前需求、实际 diff、原始失败依据和检查证据进行只读审查。没有运行 OpenCode provider 或生产队列。

审查中确认并修正了两项问题：新生成提示词仍要求外层 coverage，现改为示例和文字都要求 `spec.contract_coverage`；审阅缓存现在绑定 case-design/policy，并验证保存的报告身份，避免把旧材料结论用于新材料。宿主精确补丁同时绑定当前 job、plan-1 和预定补丁摘要，拒绝替代 A04 文本或改动非搜索适配。

最终独立结论：未发现有证据支持的未解决正确性问题。已复核 16 项聚焦测试及 2 个子用例、代码差异检查、32 分支门禁、4/4 预算拒绝回滚，以及 31 张逻辑表和 15,742 份历史文件保持一致的报告。

验证边界：恢复使用临时库和假 CLI；prepared 消费测试在首次独立设计预审 spy 处停止。没有真实 provider、下游运行或 G1 通过证据。独立审查结束时完整 13 项检查仍在运行；其最终实际结果单列于 DELIVERY 和 verification/full/checks.json，不倒填为审查者亲自执行的证据。
