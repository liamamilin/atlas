# 生活待购与灵感收藏夹（P0 本地版）

单人本地静态书签应用，只实现认知模板 P0：保存、编辑、重新分类、检索和返回原网页，并覆盖输入安全、存储失败和键盘/窄屏基础体验。书签保存在当前浏览器来源的 IndexedDB 中，不上传，不访问外部服务。

## 启动

1. 在本目录运行 `python3 -m http.server 5220 --bind 127.0.0.1`。
2. 打开 `http://127.0.0.1:5220/`。
3. 没有安装、构建或依赖步骤；`index.html`、`app.js`、`style.css` 由普通静态 HTTP 服务器提供。请勿用 `file://` 打开。

IndexedDB 按来源隔离；换主机、端口或协议会看到另一个库。浏览器清理站点数据、无痕模式结束或存储被回收都可能删除书签。当前没有备份或导出能力。

## 采用的决策

- D01：单人本地浏览器库，无服务器、账户、云同步。
- D02：原生 HTML、JavaScript 模块和 IndexedDB；静态本地预览。
- D03：仅接受无用户名/密码的绝对 http/https URL；保留 query 和 hash，使用 `URL.href` 规范化；P2 之前不做重复合并。
- D04：单层字符串分类，空白归入「收件箱」，输入新值即创建分类；编辑修改原记录 id。
- D05：写入事务 `complete` 后才显示已保存/已更新；失败保留输入和旧记录，并用 `role=alert` 说明。
- D06：P0 的 `deletedAt` 始终为 `null`；软删除、导出和导入属于 P1，尚未实现。
- D07：不抓取标题、favicon 或正文，不接分析、支付或外部 API。
- D08：无计费、成员后台或审计承诺。

## 已实现范围（P0 / F01-F07）

- 保存到默认分类「收件箱」；可选择或输入新分类。
- 编辑原记录并重新分类，不复制记录；刷新和重新打开页面后仍保留。
- 在标题、链接和分类上做大小写无关包含检索，并与分类筛选取交集；空结果显示「没有匹配的书签」。
- 每条记录为 `article`，标题为 `heading`；外部链接可访问名称为「打开原网页」，使用 `target=_blank` 和 `rel=noopener noreferrer`。
- 拒绝 javascript、data、file、相对 URL、带凭据 URL 和空标题；标题始终以文本写入 DOM，避免 HTML 注入。
- 保存按钮在初始读取完成前禁用；异步提交期间加锁，快速重复提交只产生一条记录。
- 写事务中止或数据库打开/读取失败时不显示成功、不覆盖旧记录，并保留表单输入。
- 中文标签、`role=status`、`role=alert`、键盘提交和 375px 窄屏布局。

## 未测试与限制

- 本交付未包含验收套件，也未在本会话运行 Playwright 验收；上述行为按实现说明列出，不等于独立验收已通过。
- P1 的回收站、恢复、全量导出和导入未实现；P2 的查重和批量分类未实现。
- 无云同步、账户、权限、计费、运营后台、抓取、正文归档或离线阅读。
- 无备份、加密或跨设备迁移；浏览器清理数据不可恢复。
- 只处理单页面内的本地状态；多标签页同时编辑没有实时同步，最后写入者可能覆盖另一标签页的更新。
- 没有容量、性能或 SLA 基准；未做浏览器兼容矩阵测试。
