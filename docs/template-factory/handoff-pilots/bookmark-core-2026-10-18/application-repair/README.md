# 生活待购与灵感收藏夹

一个本地单用户的个人收藏夹：把浏览时偶然看到、暂时不处理的网页链接先存起来，
之后按分类浏览或用关键词检索找回来，并一键回到原始网页。

界面为中文，服务端渲染；只使用 Python 3 标准库与 SQLite，无需安装任何依赖。

## 启动

```bash
python3 app.py --port PORT --data-dir DIR
```

- `PORT`：监听端口（必填参数，例如 8080）。
- `DIR`：数据目录；不存在时自动创建。
- 应用仅绑定 `127.0.0.1`（回环地址），不对外网开放。
- 启动后访问：`http://127.0.0.1:PORT/`

示例：

```bash
python3 app.py --port 8080 --data-dir ./data
# 浏览器打开 http://127.0.0.1:8080/
```

## 存储位置

全部持久数据都在 `--data-dir` 指定目录下：

- `DIR/app.sqlite3` —— SQLite 数据库（分类、书签、保存幂等令牌）。

删除该文件即清空收藏；停止并重新启动进程后，已保存的分类与记录仍可经界面读回。

## 已实现范围（P0 核心闭环）

- 保存链接：仅 URL 必填，标题与备注可选；未填标题时显示 URL。
- 归类：保存时可选择一个已有分类，或在保存表单里顺手新建分类；
  不选任何分类时落入“未分类”。
- 独立新建分类：左侧“分类”栏提供独立的“新建分类”表单，无需保存任何书签，
  空库也能先建好分类；创建成功后新分类立即出现在左侧分类列表中，并保持当前
  浏览视图不变，随后可用记录下方的“移动到分类”把已有记录直接移动到新分类。
- 分类校验：独立新建或顺手新建遇到空白名称、重名名称时都会显式提示且不落库，
  已填内容与其他记录保持不变。
- 移动：每条记录下方可用“移动到分类”下拉把记录改到其他分类（含“未分类”）。
- 浏览：左侧按分类浏览；“全部”显示所有记录，默认按添加时间倒序（新在前）。
- 检索：按关键词在标题 / URL / 备注 / 分类名中做大小写不敏感子串匹配。
- 打开原页：每条记录以原始 URL 为锚点，在新标签页打开原页面，query 与 fragment 原样保留。
- 空库与检索无匹配使用两条不同提示文案。
- 失败反馈：无效 URL 或非 http(s) 协议、备注超限、分类空白/重名等都会显式报错且不落库，
  并保留已填内容以便修正后重试。
- 请求体合法性：单次请求体上限为 **1,000,000 字节**。超过上限的请求在解析前即整体
  被拒绝（HTTP 413），不解析、不写入，现有记录保持不变；被拒绝的正文不会被保留。
  `Content-Length` 非法（缺失、负数、非整数）、正文不是合法 UTF-8、或字段内含无法
  解码的百分号编码时同样显式拒绝（HTTP 400），绝不静默截断或用替换字符顶替后再
  当成有效表单。
- 重复 URL：保存时若判定为可能重复，会显示“可能已存在”提示，并提供“仍然保存”动作，
  由用户显式决定是否再存一条；不会静默拒绝或静默重复。
- 重复提交保护：同一保存表单快速双击只会产生一条记录（客户端令牌 + 服务端短窗口幂等）。
- 私有：仅回环监听，无元数据抓取、无遥测；唯一的对外导航是用户点击“打开原页”。

## 明确不做（P0 之外）

- 无编辑、删除 / 回收站；分类不可重命名或删除（只能新建与选择）。
- 无导入 / 导出、无批量操作、无标签、无分页。
- 无账号、无认证、无云端同步；不支持从本机以外访问。
- 不做网页快照 / 归档、失效链接扫描与正文全文检索。
- 不做服务端网页标题抓取；标题只来自用户输入或回退为 URL。

## 已知限制与行为说明

- 备注长度上限为 **2000 字**（按 Unicode 字符计）：超过时显式报错、保留已填内容且不保存，
  绝不静默截断。这是纯可用性上限，不是数据完整性要求。
- 单次请求体上限为 **1,000,000 字节**：超限请求整体返回 HTTP 413，未解析、未写入，
  也不会声称保留了未被读取的表单内容。
- 检索为大小写不敏感子串匹配，不含正文全文索引。
- 重复判定使用最小规范化比较键（trim、scheme/host 小写、去默认端口、去路径末尾多余斜杠，
  保留 query 与 fragment）；不做 http/https 或跟踪参数变体的自动合并。
- 空状态提示只在收藏夹确实为空时显示；收藏夹非空时按设计不显示该提示。
- 未做规模 / 性能 / 延迟阈值承诺：优先保证语义正确性与数据完整性。
- 未在任何环境中实际运行验证；本目录只提供完整应用源码。
