## 验收对照

| 工作包 | 验收依据 | 证据 |
|---|---|---|
| 持久步骤 | 输入摘要、产物摘要、前序约束、同 attempt 重放、追加事件 | WorkflowService fixture |
| 断点续作 | 模型成功、入库中断后从检查点继续，零新模型调用；下载失败不能 ready | runner host fixture + 日历真实复用 |

| 停止条件 | 宿主异常、输入漂移、未知启动、预算、持续渠道故障暂停 | host fault fixture + 实际停止记录 |
