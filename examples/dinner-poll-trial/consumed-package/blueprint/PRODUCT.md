# 产品定义

同机聚餐地点投票

在同一台设备前轮流表达偏好的小组成员

为聚餐问题预设地点选项，成员用代号单选并可改票，查看汇总，在结束后冻结投票，必要时重开。

1. 主持人创建问题及2–8个地点选项
2. 成员在同一设备用代号投一票
3. 成员以相同代号改票，汇总保持一人一票
4. 主持人结束投票，此后不能再投或改票
5. 需要继续时重开并再次投票，刷新重启后保留结果

- 两人分别投不同选项时总数2且各1；一人改票后仍2，变成0和2
- 关闭时再投返回poll_closed且结果不变；重开后允许第三人投票，总3
- 选项必须属于该投票，重复选项或空代号被拒绝；不同投票互不混入
- 刷新及同目录进程重启后状态和汇总一致，平票如实显示不擅自选赢家

- R01 在同一台设备前轮流表达偏好的小组成员: 为聚餐问题预设地点选项，成员用代号单选并可改票，查看汇总，在结束后冻结投票，必要时重开。
