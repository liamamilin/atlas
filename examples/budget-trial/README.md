# 月有度 · 个人极简月度预算（辅助试用）

Python 3.10+，只用标准库＋SQLite，无需安装依赖或修改源码。解压源码包、进入 budget-trial 目录后：

```sh
python3 app/serve.py --port 5274 --demo
```

打开 **http://127.0.0.1:5274/**。在Atlas仓库根目录可运行 `python3 examples/budget-trial/app/serve.py --port 5274 --demo`。

- 选择月份，点“创建本月计划”。填写预计收入，添加用途（如食品1000元、交通200元）。
- 在“记一笔支出”选择日期、用途、金额并保存。顶部与用途表显示计划、实际、剩余；超支保留负数。
- 点支出行“编辑”，修改后保存，即时重算；分类行可改预算，也可在两个用途之间等额转移计划。
- 点“保存本月计划为模板”，再选另一个尚未创建的月份并创建。复制计划和预计收入，不复制支出、不结转剩余。旧月份不受影响。
- Ctrl+C停止，再执行同一命令即可恢复数据。data/budget.sqlite3是独立本机数据；可用 `--data-dir /绝对路径` 指定，重启要保持一致。先停应用再复制data目录备份。

`--demo`只在新数据库首次初始化时建立两个有“[演示]”标记的预算用途，不会重启重复添加。当前运行实例的两笔“[试用]”早餐/午餐是浏览器验收示例，不是真实财务资料。源码包不带该数据库。

范围：单人、本机、人民币两位小数，金额按整数分保存；无账户/银行连接/云同步/多币种，不作金融建议。未提供支出删除、分类删除、导入导出和复杂报表，错误支出可编辑；这些进入后续待办。并发压力、完整错误矩阵与严格认证未作通过声明。不要暴露到公网。

来源见SOURCE.json和TRIAL_SCOPE.md；这是先导出独立模板与标准开发包、再由Codex读取实现的辅助应用，不是严格G1/T08或正式开发队列交付。

定向回归：`python3 -m unittest discover -s tests -v`。原模板HTTP验收程序和真实浏览器旅程分别记录，不互相替代。
