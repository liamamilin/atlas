# 会后有据 · 多项目会议笔记（辅助试用）

Python 3.10+，只用标准库和 SQLite。解压源码包，进入 meetings-trial 目录：

```sh
python3 app/serve.py --port 5275 --demo
```

打开 **http://127.0.0.1:5275/**。在 Atlas 仓库根目录可运行 `python3 examples/meetings-trial/app/serve.py --port 5275 --demo`。

- 先在快速捕获区填写正文，保存到收件箱；也可以直接选择项目。
- 创建项目，打开笔记后移动到对应项目。笔记同一时刻只属于一个项目。
- 点“编辑”，补充结论或 Markdown 表格，点击保存。正文保存为原文，不渲染 HTML；**没有自动保存**，离开编辑页前请保存。
- 置顶笔记在日期或标题排序时始终排在前面。归档笔记不出现在默认活跃列表，搜索仍能找到。
- 全库搜索按标题和正文进行不区分大小写的子串匹配；选项目后只搜该项目。回收站中的笔记不进入普通搜索。
- 删除进入回收站，打开后可以恢复到原项目，保留正文、置顶与归档状态。本版不自动清空、不到期删除。
- Ctrl+C 停止，再执行同一命令即可恢复数据。默认数据为 data/meetings.sqlite3，可通过 `--data-dir /绝对路径` 指定；重启保持一致。备份时先停止应用再复制 data 目录。

`--demo` 只在新数据库首次初始化时创建一条带“[演示]”标记的笔记和项目，不会在重启时重复添加。当前运行实例中的“试用”笔记属于浏览器操作示例；源码包不包含该数据库。

范围：单人本机使用。未提供附件、富文本渲染、语音、导入导出、云同步、多人权限、项目删除/整项目归档或永久删除。未作并发压力、完整错误矩阵或严格认证通过声明。不要暴露到公网。
